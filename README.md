# 🛒 E-Commerce Sales Dashboard (Excel Project)

## 📊 Project Overview
This project presents an interactive Excel dashboard analyzing e-commerce sales for **Viva Calif**.  
It highlights customer behavior, product popularity, delivery performance, and regional sales trends using pivot tables, charts, and map visuals.

## 🛠️ Tools & Techniques
- Microsoft Excel (Pivot Tables, Pivot Charts, Map Charts)
- Data Cleaning & Transformation
- KPI Tracking (Orders, Quantity, Revenue, Ratings, Delivery Days)

## 🔑 Key Features
- **KPI Summary**:  
  - Total Orders: 2,400  
  - Total Quantity Sold: 11,997  
  - Total Revenue: ₹649,000  
  - Avg. Customer Rating: 4.0  
  - Avg. Delivery Time: 2.3 days  

- **Trend Analysis**: 13-week sales trends for quantity and revenue.  
- **Purchase Channels**: Breakdown by App, Website, Instagram, Partner App, and Target.com.  
- **Order Size Distribution**: Frequency of purchases (single-item vs bulk).  
- **Popular Products by Gender**: T-Shirts, Jeans, Sneakers, Tank Tops, Bikinis, Shorts, Sundresses, etc.  
- **Customer Demographics**: Female (52%), Male (35%), Others (8%), Unknown (7%).  
- **Regional Sales Map**: County-level sales in California, with Los Angeles, San Diego, and Sacramento as top contributors.  
- **Delivery Performance**: Most orders shipped within 1–3 days.  
- **Customer Satisfaction**: Majority of customers rated 4–5 stars across months.

## 🎯 Business Insights
- Los Angeles County generated the highest revenue (~₹71,609).  
- Sneakers and Jeans are consistently popular across genders.  
- Website and Target.com drive significant sales compared to Instagram.  
- Faster delivery (1–3 days) correlates with higher customer ratings.  

## 🚀 How to Use
1. Download the Excel file from this repository.  
2. Open in Microsoft Excel (2016 or later).  
3. Use slicers and filters to explore by product, gender, and region.  
4. Review KPIs and charts for actionable insights.
